# 本机 CFG 工作台布局

工作台在同一页面组织草稿编辑、静态检查、绑定预览、本机版本和分享预览。现有编辑区与“检查结果 / 绑定预览 / 保存版本”切换保留；页面先显示完整当前名称与实际保存状态，再区分导入/示例、编辑及显式保存/下载/分享操作。

导入文件、分享参数和保存版本的预览与当前草稿分开，预览显示“尚未载入”，保留载入、直接下载与取消。示例沿用原行为：非空草稿先预览，空草稿直接载入。取消只关闭本次预览，不撤回已经下载的文件；删除版本不会删除当前草稿。原迟到读取隔离与失败导入保留行为不变，不声称终止正在进行的解码。

草稿保存错误、跨标签页冲突及恢复操作仍当前可见。原记录备份和显式重新保存相邻；重新保存仍需原确认。写入失败时，页面中的草稿/版本可能只保留在当前会话，版本列表不代表已经持久化。原记录备份沿用其现有读取规则，不承诺包含本次未保存修改；当前 CFG 下载仍可单独带走正在编辑的配置。

名称最多 80 字符、内容最多 256 KiB、最多 20 个本机版本保持不变。检查仍最多展示 150 条诊断，未知命令保留，顶层静态结果不执行 alias / exec，也不代表 CS2 中的实际效果或部署。绑定追加到文件末尾，同一按键以最后一条顶层设置为准。按键预览不触发游戏动作；Tab / Escape 不录入按键，Tab 可移出焦点。

分享链接包含生成时的完整配置，不同步后续编辑。敏感内容提示紧邻复制/下载/分享，开发模式的本地预览链接提示保留；该提示取决于原开发模式条件，并非新增主机可达性检测。剪贴板只在显式点击后写入，成功和失败仍由现有 CopyButton 处理，没有自动读取剪贴板、网络请求或下载。

普通文件/版本说明置于原生可展开帮助，当前错误、限制和风险不折叠。产品改动仅该页面 JSX 与 `.cfg-workbench` 限域样式；所有处理函数、内联事件、效果、请求围栏、禁用条件、算法、存储、默认值、分享编码、文件名/MIME 和原 E2E 保持。

验证使用 Vitest/jsdom，实际组件与模块配合合成文件、存储、延迟流、剪贴板 promise 和下载接收端。8 个完整聚焦文件中的 99 个不同案例有通过记录，其中新增 41 项；局部 ESLint 通过。既有 CFG E2E 收集 5 项、执行 0 项。真实浏览器、视觉/移动布局、原生键盘/IME、用户文件选择、游戏、剪贴板许可和真实下载均未在本批验收。
