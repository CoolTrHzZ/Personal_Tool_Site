# 工具目录 → JSON 工作台

本批只调整 `/#/tools` 与 `/#/tools/json`，其他页面仍按完整 UI 矩阵分批处理。
已发布 URL 工作台、JSON 排序、DST、CFG 和 Admin 索引状态保持原行为。

## 目录

- 搜索、状态和排序集中在同一区域，分类位于其下；匹配数量紧邻列表。
- 每个工具保留一个打开入口，显示名称、说明、类别与版本；收藏为独立动作。
- 筛选仍保存在页面地址，工具内返回和浏览器返回保留原筛选。
- 加载、空目录、无匹配、失效筛选及停用状态分别呈现。站点配置的目录说明收在可展开帮助中，当前筛选不会被折叠。

## JSON

- 输入和输出分区；桌面并排，窄屏纵向排列。示例/清空属于输入区，格式化/压缩/按键排序集中在输入下方，复制属于有效输出区。
- 原有标签、占位示例和错误关联保留。详细规则可展开；当前错误、输入已更新、无可复制结果与复制失败始终在对应区域显示。
- 排序仍为显式操作，不改变输入或数组顺序；整数索引键优先按数值升序，其余键按 UTF-16 码元升序。普通格式化和压缩不自动排序。
- 保留超安全整数、非有限数拒绝。编辑或清空会让旧结果失效；仅点击复制时写入剪贴板，写入完成才提示成功，失败不会冒充成功。

## 本批验证边界

定向入口为 `tests/json-sort.test.js`、`tests/json-sort-ui.test.js`、`tests/tools-json-layout.test.js`；均由现有 `tests/**/*.test.js` 收集。新增组件用例运行真实 Router、ToolsPage、JsonTool、ToolCard 和 CopyButton，目录数据、站点显示开关、存储与剪贴板使用合成环境。显示开关不是认证权限。

这些检查不证明真实浏览器的 Tab 顺序、读屏、IME、手机软键盘、视觉布局或剪贴板授权。当前候选未做原生视觉验收、构建或 E2E；上一发布版的构建通过不能继承为本候选通过。旧 resource-atlas hover 失败仍未解决；本批不改变其断言、重试、样式或诊断流程。
