# Admin 工具索引状态

“运行中”只表示 Admin 可以响应请求；不代表工具索引已成功同步。

`GET /api/system` 的 `index` 记录当前 Admin 进程最近一次已完成的索引重建：

- `unknown`：尚无已完成的重建结果；界面显示“尚未确认”。
- `synced`：重建及索引文件的原子替换成功；界面显示“已同步”。
- `failed`：重建失败；界面显示“同步失败”，不返回原始异常或文件路径。

启动和已有重建入口（包括内容操作中的既有重建）更新此记录。之后一次合法重建成功可恢复为 `synced`；读取系统状态不会触发重建或重试，也不新增后台恢复。

状态在进程内保存，重启后重新记录；它不是持续磁盘校验、内容校验、浏览器验收或部署成功证明。现有内容校验与发布结果仍分别展示。进程外修改索引不会主动刷新这条记录。
