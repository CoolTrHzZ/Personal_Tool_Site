# URL 工具：模式与结果复制

- 通过“解析 URL / 编码 / 解码”选择任务，再执行当前操作。切换模式保留原始输入并清除旧结果，不自动转换或访问网址。打开页面仍有可复制的编码示例；“试用示例”按当前模式生成结果。
- 输入与结果分栏，窄屏上下排列。解析结果区分规范化地址、地址组件及保持原顺序的查询参数；重复键与空字符串保留。详细规则折叠，禁止凭据、仅本地处理及规范化提示仍直接显示。
- 解析成功后，在“复制内容”中选择规范化 URL 或一个组件，再点击对应复制按钮。复制的是该返回字段的精确值：协议不含冒号，主机不含端口，路径保留百分号编码，片段含 `#`。默认端口/空片段不复制占位说明。
- 复用现有剪贴板写入：仅明确点击才写入，成功提示等待写入完成；失败提示手动选择结果。输入、模式、结果或复制组件变化后，旧反馈和迟到请求不再影响当前结果。没有剪贴板读取、历史记录、网络请求或自动打开地址。

解析仍仅接受无凭据的绝对 HTTP(S) URL。现有长度、查询项数、序列化输出限制以及非法编码检查不变。查询按表单规则将 `+` 解为空格，组件解码保持 `+`；原文从不被规范化结果覆盖。

验证范围：实际 URL 组件在 React/jsdom 中使用合成输入和模拟剪贴板 Promise，另有原解析 helper 与共享复制行为测试。现有 URL 浏览器用例只增加显式选择解码模式，原断言保留；本轮未运行浏览器、真实剪贴板或视觉验收。真实键盘原生激活、窄屏布局与浏览器复制权限仍待独立验收。
