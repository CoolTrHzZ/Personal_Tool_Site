# 配置差异工作台布局

本批仅覆盖矩阵 T06 `/#/tools/config-diff`。格式与比较选项归组，示例明确“填入示例并对比”；双侧编辑与文件入口保持对应。“开始对比”为主动作，交换/清空独立为编辑辅助。比较结果集中展示行数和双侧诊断，表格旁保留“只显示变更”；复制/下载归入变更报告区。

一般使用与报告说明可展开。本地处理、不上传/不自动保存、每侧 256 KiB / 2000 行、当前格式的检查局限始终可见。错误、未进行格式校验和检查范围限定不会隐藏或改成“验证通过”。未比较时不显示无差异结论。

输入默认值、算法与所有原处理函数保持。格式切换仍使比较与旧导入失效而不自动清除旧错误；失败导入保留文本和已有比较。只显示变更仅过滤表格，不影响报告。复制由用户明确点击，成功必须等待写入完成；失败可见，不读取剪贴板。保留原字段标签、文件控件、输入节点及可聚焦差异区，不主动抢焦点。

样式只作用于 `.config-diff-workbench`，复用现有工作台设计。相关完整测试入口为 `tests/config-diff.test.js`、`tests/config-diff-import.test.js`、`tests/tool-onboarding.test.js`、`tests/tool-copy.test.js` 与 `tests/config-diff-layout.test.js`；既有四个配置差异 E2E 场景保留。

合成组件测试不等于原生键盘、视觉、IME、文件选择/下载或剪贴板许可验收。本批不执行浏览器、构建或全套测试；独立复核后的正常托管验证仍待完成。旧 resource-atlas hover 失败和其他矩阵项待办继续保留；本批不代表全部 UI 完成。
