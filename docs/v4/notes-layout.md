# 笔记与运维手册阅读布局

本批覆盖 P07 笔记列表和 P08 阅读详情。列表将全文搜索、类型与项目筛选放在同一组；全库统计与当前筛选结果数分开。记录卡片显示完整标题、记录 ID、类型、关联项目 ID 和原记录更新时间，同名记录可通过 ID 区分。原始排序、全文匹配、失效筛选选项、空库/无匹配状态和返回参数保持。

详情先显示所选记录的完整身份、类型、关联项目 ID 与原更新时间，再呈现原 Markdown 正文。更新时间按记录原值显示，缺失或空白显示“未知”，不解析或修正日期，也不表示最新运行状态。正文内原有标题和内容保留，身份头不替代或改写文档正文。

关联入口沿用现有站点页面显示条件和数据筛选，不新增访问权限、可用性检查或自动请求；原有项目/CFG 关联数据规则未变。筛选和页面导航不触发自动复制、下载或外链访问。没有新增编辑器、执行入口或持久状态。

产品改动仅两页 JSX 和 `.notes-page` / `.note-page` 限域样式，原 `projects.css` 共享及 ProjectsPage 规则保持原文。Markdown 渲染/安全处理、数据、筛选与 URL 逻辑、复制围栏、document title 和下载 helper 未改。
