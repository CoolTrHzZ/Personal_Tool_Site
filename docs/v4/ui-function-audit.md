# UI 与功能审计 · 2026-09-08

本轮以现有页面和真实操作链路为范围，沿用静态 GitHub Pages 前台及本机 Admin。

| 审计发现 | 已实现的改进 |
| --- | --- |
| 网站导航仅能浏览全部分类 | 增加名称、域名、说明搜索，与分类、标签组合筛选；地址保留条件，显示结果数及清除入口。 |
| AI 搜索会重置类型，详情无法稳定分享 | 类型、搜索和工作流分类统一保存在 URL；通过资源 ID 打开详情，支持刷新、复制链接、失效提示及返回工作流。首页与命令面板使用同一入口。 |
| 长列表进入详情后返回丢失位置 | 列表返回及浏览器后退恢复滚动位置；键盘跳过导航、当前页标记和切页焦点完整衔接。 |
| 多个标签表单仍依赖手输，标签目录遗漏内容来源 | 所有标签表单统一候选、多选、模糊匹配和自定义输入；目录统计、改名和删除覆盖全部八类内容。 |
| 仅修改分类、标签、图标时可能丢失草稿 | 选择器纳入草稿记录、恢复和离开保护；原记录 ID 仍不可由草稿覆盖。 |
| 项目编辑的慢请求可能覆盖后打开的表单 | 增加请求版本和当前视图检查；依赖加载成功前保留原编辑器，过期请求不再替换表单。 |
| 弹窗只有入场动画，背景焦点隔离不完整 | 增加退场与快速重开处理，退出期间保持隔离，兼顾嵌套弹窗、隐藏元素和触发器焦点恢复。手机弹窗避开实际顶栏高度，全屏工具内的命令面板可正常显示并逐层关闭。 |
| 关闭动效后部分图标仍瞬移，触屏悬停反馈不合适 | 补齐减少动效规则、键盘焦点反馈和触屏点击尺寸；主题与动效设置实时同步到同源标签页。 |
| 工具提示固定倒计时，阅读期间会消失且不能手动关闭 | 统一提示生命周期，支持关闭、悬停/聚焦暂停消失及平滑退场。 |

## 验证范围

- 单元与 API 测试：全来源标签统计/合并/删除、写失败回滚、CFG 控制字符与 EXE 字节保留、标签选择器、草稿、弹窗隔离和提示生命周期。
- 浏览器回归：前后台既有功能、新筛选与分享流程、手机布局、退出动画、键盘操作、浏览位置恢复及跨标签页偏好同步。
- 发布检查：数据校验、ESLint、TypeScript、生产构建，以及 `./`、`/` 和 `/Personal_Tool_Site/` 三种静态部署路径。

## 验证结果

- 数据校验、ESLint、TypeScript、152 项单元/API 测试及生产构建通过。
- 110 项浏览器用例均已验证通过。全量运行前 104 项通过后，原有 Vite 预览进程退出，末段出现页面加载/连接失败；改用测试程序管理的服务，重跑受影响的两个文件，10 项全部通过。
- 三种静态部署路径均通过八个页面、刷新、关联跳转、CFG 原文下载、EXE 字节一致性与工具 Bridge 检查。
- 已人工复核 390px 手机导航、资源详情和后台标签候选布局。

标签变更只更新元数据。CFG 正文、历史版本与桌面工具下载文件保持原样。分享 AI 详情只携带资源标识，不携带填写的提示词变量。
