# AI 上下文工作台布局

本批仅覆盖完整矩阵 T07–T09：任务列表与名称、说明/材料/输出、导入删除及存储恢复。当前任务完整名称与选择器并列；新建、示例、复制为次操作，删除与原确认单独呈现。任务说明、参考材料和只读 Markdown 保留三段卡片，既有字段顺序、标签、placeholder、原生焦点和材料折叠控件保持。

名称在离开输入框或原有切换动作中保存；名称未保存/无效与正文自动保存状态保持区分。存储失败或其他标签页冲突在当前任务区域可见，已存草稿备份与明确替换本地记录相邻。备份读取本机已存原记录，不包含当前未保存修改；替换会保存本页任务列表并覆盖该本地记录。原有 pending 草稿、恢复事件、失败重试与迟到读取隔离不变。

容量分开呈现：最多 20 个任务、全库内容 3 MiB；当前任务说明与材料合计 1 MiB（界面按 1024 KiB 展示）；最多 20 份材料、每份 256 KiB。字节和数量仍由原算法计算，不使用字符数冒充字节。Markdown 字符数仍沿用既有计算。文件只在本机读取，工作流只是本地任务模板，不执行步骤或调用模型。

JSON 导入预览明确标为尚未应用，并显示当前替换目标。作为新任务保留现有任务；替换只更换当前任务正文和材料，任务名称及其他任务保持；取消不应用预览。JSON 和 Markdown 只导出当前任务正文与材料，不包括任务列表、任务名称及名称草稿。敏感信息提示紧邻显式复制和下载动作；不会自动读写剪贴板、上传或调用模型。复制成功/失败仍由原共享 CopyButton 在写入结果后反馈。

只修改此页面 JSX，样式追加在 `.ai-context-workspace` 下。所有 handlers、inline 事件、refs/revision/cancel/disabled、默认值、context/store 算法、文件名/MIME、导出 payload 和共享组件逐字保留。一般帮助独立折叠，错误、保存冲突、导入目标及恢复风险不放入折叠帮助。

聚焦入口为 `ai-context.test.js`、`ai-context-name.test.js`、`tool-persistence.test.js`、`tool-onboarding.test.js`、`tool-copy.test.js` 和新增 `ai-context-layout.test.js`，使用实际 ReactDOM 与现成 Vitest/jsdom、合成存储/文件/下载/剪贴板接收端。既有 `tool-display-ai-context.spec.js` 的 4 个浏览器合同保持原样。本轮不运行浏览器、真实文件选择、真实用户下载、原生剪贴板权限、模型或服务；DOM/静态检查不等于原生视觉、移动布局、IME 或键盘验收。

已发布基线的 CI 绿色不能替代本候选验收；旧 hover 失败及根因未知记录继续保留。完整 94 组矩阵仅将 T07–T09 标为本批候选，其他未改页与原生验收缺口保持，不宣称全部 UI 完成。
