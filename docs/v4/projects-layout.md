# 项目目录与发布详情布局

本批覆盖矩阵 P09 `/#/projects` 与 P10 `/#/projects/:id`。目录把搜索、类型、维护状态和置顶筛选归组，结果数量保持可见；卡片依次展示项目身份与维护状态、发布文件元数据，再提供“查看详情”、置顶及已有下载动作。一般目录说明使用原生折叠帮助。

详情先保留项目身份、维护状态和各自独立的外链/置顶，再集中展示版本、平台、文件名、大小、更新时间、完整 SHA256 与显式下载。缺版本/平台仍为“待补充”，没有文件不生成下载或校验复制入口；“已暂停”“已归档”不等于无文件。下载仅获取文件，下载不代表安装、运行验收或已部署，这一限制在目录和文件详情当前可见。Markdown 说明、关联手册与 CFG 保持原显示条件。

筛选 URL 与 replace 行为、排序、返回原参数、精确下载地址和 filename、置顶读取/保存失败重试/storage/恢复事件、Markdown 清理和共享复制组件均不变。复制仅在用户点击后写入，成功等待完成，失败明确显示。不打开外链、执行文件、新增网络查询或自动读写剪贴板。

样式仅追加 `.projects-page` 限域规则；`projects.css` 原有共享规则及 NotePage、ToolShell、CopyButton 均保持。测试使用实际 React/DOM 组件及合成数据；不代表原生移动布局、键盘/IME、下载文件字节、系统剪贴板权限或运行验收。既有 `e2e/workspace-redesign-projects.spec.js` 全部断言保持，本批浏览器执行为 0。
